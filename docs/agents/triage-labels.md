# Triage labels

Engineering skills 使用五个 canonical triage role。本文件将这些 role 映射到仓库 issue tracker 的实际标签字符串。

| mattpocock/skills 中的标签 | Tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待 maintainer 评估 issue |
| `needs-info` | `needs-info` | 等待 reporter 补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提及某个 role（例如“应用 AFK-ready triage label”）时，使用表中对应的 tracker 标签。

如果 tracker 的标签命名发生变化，应修改右侧映射列。
